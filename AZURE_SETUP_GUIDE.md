# Azure Setup Guide — Step by Step

Everything you need to collect before we start the migration.
Follow each step in order, copy the values into the checklist at the bottom.

---

## Step 1 — Find your Subscription ID

1. Go to **portal.azure.com**
2. In the top search bar, type **Subscriptions** → click it
3. You'll see a list — click your subscription name
4. On the overview page, copy the **Subscription ID** (looks like: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`)

> If you have multiple subscriptions, pick the one your organization uses for production workloads.

---

## Step 2 — Choose a Region

Pick the region **closest to your users**.

| Your users are in | Use this region value |
|---|---|
| India | `centralindia` |
| US (East Coast) | `eastus` |
| US (West Coast) | `westus2` |
| Europe | `westeurope` |
| Southeast Asia | `southeastasia` |

Write down the **region value** (the code, not the display name).

---

## Step 3 — Create a Resource Group

A Resource Group is a folder that holds all your Azure resources together.

1. In Azure Portal → search **Resource groups** → click **+ Create**
2. Fill in:
   - **Subscription**: your subscription
   - **Resource group name**: `quixai-prod-rg`
   - **Region**: the one you chose in Step 2
3. Click **Review + create** → **Create**
4. Copy the resource group name: `quixai-prod-rg`

> **Naming rule used**: `{app}-{env}-rg`
> Always lowercase, hyphens only, no spaces.

---

## Step 4 — Choose your PostgreSQL Password

You need to create a password for the database admin account. It must meet these rules:

- At least **8 characters**
- At least **one uppercase** letter (A–Z)
- At least **one number** (0–9)
- At least **one symbol** (`!`, `@`, `#`, `$`, etc.)

Example of a valid password: `QuixAI2025!prod`

> **Do not use**: `@` in the password if possible — it can cause issues in connection strings. Use `!` or `#` instead.

Write down:
- **Admin username**: `quixaiadmin` ← use this exactly
- **Admin password**: *(your chosen password)*

---

## Step 5 — Find your GitHub Repo URL

1. Go to **github.com** and open the `quix-ai` repository
2. Click the green **Code** button
3. Copy the **HTTPS** URL

It will look like:
```
https://github.com/YOUR-USERNAME/quix-ai.git
```

Write down just the part without `.git`:
```
https://github.com/YOUR-USERNAME/quix-ai
```

---

## Step 6 — Naming Conventions for All Resources

Use these exact names when I create the resources (or when the portal asks you to name something).

| Resource | Name to use | What it is |
|---|---|---|
| Resource Group | `quixai-prod-rg` | The folder for everything |
| PostgreSQL Server | `quixai-prod-db` | The database server |
| Database name | `quixai` | The actual database inside the server |
| DB Admin user | `quixaiadmin` | The database superuser |
| App Service Plan | `quixai-prod-plan` | The compute plan (like a VM size) |
| App Service (Web App) | `quixai-prod-app` | The running Next.js app |
| Your app's URL | `quixai-prod-app.azurewebsites.net` | Auto-generated by Azure |

> **Naming rules followed:**
> - All lowercase
> - Hyphens only (no underscores, no spaces)
> - Pattern: `{app}-{env}-{resource-type}`
> - `prod` = production environment

---

## Step 7 — Install Azure CLI (if not already installed)

Open your terminal and check:
```bash
az --version
```

If you get "command not found", install it:

**Mac:**
```bash
brew install azure-cli
```

**Windows:**
Download from: https://aka.ms/installazurecliwindows

After installing, log in:
```bash
az login
```

A browser window will open — sign in with your Azure account.
When it says "You have logged in", come back to the terminal.

---

## Step 8 — Verify CLI Access

Run this command:
```bash
az account show
```

You should see your subscription name and ID printed. Copy and confirm the **id** field matches what you found in Step 1.

If you have multiple subscriptions, set the right one:
```bash
az account set --subscription "YOUR-SUBSCRIPTION-ID"
```
